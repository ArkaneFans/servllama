# 模型能力配置与 UI 统一

2026-10-04，`2.0.0-dev.26+40`。

## 供应商和模型的边界

供应商负责协议、地址、凭据、启用状态及模型清单。图片输入和工具调用属于清单中的具体模型，不能用一个供应商开关代表所有模型。

供应商编辑页采用底部“配置 / 模型”标签，可以点击或滑动切换。参考 RikkaHub `SettingProviderDetailPage.kt` 的双页组织和 Kelivo 的模型编辑入口，使用 ServLlama 自己的雾紫胶囊标签与卡片样式。

- **配置**：供应商信息、连接配置、密钥、连接测试。
- **模型**：模型数量、搜索、手动添加、获取候选列表和删除。每项显示模型图标、ID 与“文本 / 图片 / 工具”能力摘要；点击条目打开能力底部面板。
- **能力面板**：图片输入和工具调用分别开关。“完成”更新编辑草稿；右上角关闭、下滑或系统返回放弃面板内未完成的改动。
- 两页共享同一份草稿，供应商页右上角“保存”统一提交。切换标签不丢名称、地址、密钥、模型列表和能力修改；直接返回不保存。获取模型不会覆盖已有能力，失败或取消不清空清单。

新手动添加或从端点选入的模型默认只有文本能力。用户根据模型说明开启图片、工具能力；`/models` 等端点只提供候选 ID，不证明模型能力，不按模型名称自动猜测。已有模型保留原先设置。

## 数据与运行闭环

继续使用 `AiConnection`、`ai_connections.config` 和 `models: List<String>`，增加 `modelCapabilities: Map<String, ModelCapabilities>`。不增加表、数据库迁移版本、供应商 SDK 或第二份模型目录。

读取旧 JSON 时，将供应商级 `supportsImages`、`supportsTools` 展开到当时已经保存的模型。新 JSON 只写逐模型能力，删除旧开关字段。删除模型时清理对应能力；保存时归一化模型 ID 并同步能力键，不从历史会话补回模型。此转换在原记录读取处完成，不扫描 Run、会话或文件。

`ChatRunConfig.capabilities` 按本次 `modelId` 读取能力；Run 的连接快照仍保持冻结：

- 图片能力控制聊天添加图片入口，运行时同时校验实际请求中的图片。历史图片或已有草稿附件不静默删除，遇到不支持图片的目标会报错，用户可换回支持的模型。
- 工具能力控制工具定义、调用循环及 MCP 会话建立。关闭工具后，原有静态 Skill 文本回退仍可使用。
- 撤销能力时，`authorizedBy` 只比较当前 Run 所用模型。同供应商的其他模型不会因这项修改被取消；新增能力在下一次 Run 生效。
- 禁用供应商、删除模型、修改凭据域等既有撤权规则继续生效。助手对本地工具/技能/MCP 的授权与模型是否具备调用能力仍分别判断。
- 本地 llama.cpp / MNN 保持原运行时边界和 HTTP 路径，不出现在远端供应商管理页。

## UI 梳理结果

| 范围 | 本轮处理 |
|---|---|
| 供应商设置 | 底部双标签，信息/连接分组，模型可搜索，能力独立面板，主次操作统一 |
| 助手设置 | 头像与名称、系统指令、默认模型、能力授权分组；系统提示词的提示文字置顶；保留一个编辑草稿 |

| ASR/TTS 与音色 | 模型/参数/文本分组，音色资料与试听分组，去掉模型选择器重复间距，统一任务列表留白 |
| 设置、服务器参数 | 复用共享分组；旧文本设置组件不再覆盖主题的填色、边框和内边距 |
| 服务器、模型文件、调试日志 | 服务器入口恢复 18 dp 圆角；模型文件卡片和调试日志使用主题表面色，日志仍保留等宽排版 |

共用 `SettingsSection.form`，内部为 16 dp 间距和留白，外部仍用 `FormListView` 和 20 dp 页边距。分组表面使用 18 dp 圆角并裁剪交互反馈；输入框继承 14 dp 圆角、表面色和焦点描边。辅助说明用 `bodySmall`，多行输入标签靠上，说明和校验文字可换行。没有改动雾紫配色、顶部消息位置、无扩散水波的按压反馈或导航失焦规则。

## 验收步骤

1. 设置 → 供应商 → 编辑：配置页不再有图片/工具总开关。切换底部“模型”，手动添加或获取候选，新模型摘要为“文本”。
2. 为同一供应商的两个模型分别开启图片、工具能力。保存并重新打开，确认设置各自保留；新增/移除模型不改变其他模型的能力。
3. 改名称、切换标签、调整能力再保存，确认一起生效；另一次编辑直接返回，确认所有修改均放弃。能力面板关闭应只放弃当前面板改动。
4. 聊天选择关闭图片能力的模型，“+”不可用；开启后恢复。选择支持工具的模型与已授权助手验证调用，关闭后不向模型发送工具定义。仅修改另一模型的能力不应取消当前 Run。
5. 检查助手、用户档案、MCP、语音和服务器页面的浅/深色、360 dp、大字体、键盘场景：分组/输入间距一致，内容可滚动，保存和底部标签可访问；返回不会重新弹键盘。

本轮没有连接 ADB 设备。真实供应商的图片请求、工具调用和运行中撤权，以及系统图片选择器/设备字体表现需真机复核；测试使用本机模拟服务和测试数据。

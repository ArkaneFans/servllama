# UI 原语样板

2026-10-02，`2.0.0-dev.21+35`。侧边栏底部的“UI 原语”进入独立样板，与“迁移演示”并排。返回后侧边栏保持展开，原会话和草稿不变。

## 设计方向与参数

以中性灰白和紧凑分组为基底，采用 Material 3 的浅色选中容器、胶囊操作按钮及明确状态反馈。通过表面色差和留白组织信息，不依赖重阴影；主色只用于重点操作、选中与局部图标。

右上角调色盘菜单提供「雾紫」和「茶紫」两种配色，明暗按钮独立控制亮度。雾紫保留原来的灰白与蓝紫色；茶紫在紫调里融入暖茶灰，并给中性背景、辅助文字和描边增加轻微暖意。形状、密度、排版和语义状态保持一致，便于比较。

卡片圆角 18 dp，表单圆角 14 dp，弹窗圆角 24 dp；页面水平边距 20 dp。标题 24/20 sp、分组标题 16 sp、正文 15/14 sp、辅助文字 12 sp；正文行高 1.5–1.6。按钮使用至少 48 dp 的操作区域，图标本身保持 18–22 dp。徽标使用文字配合颜色，避免只依赖颜色判断状态。

## 页面与交互

- **视觉基础**：设计导语、明暗色板及色值、文字层级、间距和圆角、图标样板。
- **交互组件**：主按钮、次按钮、描边与文字按钮、禁用态、底部模型选择、确认对话框、顶部消息提示、名称校验、开关、滑块与数值输入、筛选标签及进度模拟。
- **场景示例**：用户气泡、助手名称与图标、可展开工具记录、正文和末尾时间/模型、固定底部输入框、设置分组及模型卡片。发送仅替换页面中的样例消息并回到消息位置，不调用模型；“复制反馈示例”只展示提示，不写剪贴板。

初始配色为雾紫，亮度跟随当前应用主题。切换配色即时作用于三个页签及随后打开的对话框和模型弹窗，保留当前输入、模型选择、所在页签及明暗模式。演示状态在页面内共享，例如模型选择同步到输入栏；退出后重置，不修改全局主题或真实用户配置。

## 数值选择与消息反馈（dev.18）

### 滑块 + 右侧输入框

同一行左侧滑块、右侧 108 dp 数值框，标题旁标注范围。示例温度范围 0–1：拖动按 0.1 粗调，输入允许最多两位小数，例如 0.65，不会被滑块步长取整。两者只维护一份有效值。

输入有效数字时立即同步滑块；编辑过程保留 `0.` 等中间文本，提交或失焦后统一显示（如 `0.60` → `0.6`）。兼容点号和逗号小数分隔符。空值提交、非数字、超范围及超出两位小数时，显示红色边框与行内说明，保留上次有效值；不会静默截断或纠正。重新输入有效值或拖动滑块即可恢复。

### 顶部 Message

预览中的原 SnackBar 反馈改为顶部居中消息：AppBar（含页签栏）下方 12 dp、左右至少 16 dp、最大宽 440 dp、圆角 14 dp、轻阴影。图标、文字和浅色语义容器共同表达成功、信息、警告和错误；四种类型均有独立演示按钮，并适配深色主题。

dev.20 将消息宿主放在 Scaffold 的内容区域内，直接跟随 AppBar 的实际高度；进入动画从下方轻移，绘制范围限制在内容区，标题、返回、主题切换和页签始终可操作。

展示 3 秒后自动消失，可点关闭按钮提前关闭。新消息替换旧消息并重新计时，不排队堆积；进出使用 180 ms 淡入淡出与轻微位移，跟随系统减少动画设置。提示自身接收触摸，其余区域仍可操作；长消息换行，极长文本限制高度并可滚动。加入无障碍 live region。点击切换页签时清除，退出页面时销毁定时器。

消息组件用于短暂操作反馈；字段错误仍保留行内展示，确认操作仍用对话框。此次只更新 UI 原语页，业务页面的 SnackBar 待整体 UI 重构时统一评估替换。

## 实现边界

正式应用与原语页现在复用 `shared/theme/app_visual_theme.dart`、`shared/widgets/numeric_slider.dart` 和 `shared/widgets/app_message.dart`。`preview_theme.dart` 仅保留配色选项与委托；`ui_primitives_page.dart` 继续维护独立演示状态，不访问业务数据。正式应用固定使用雾紫，茶紫只供原语页比较。页面通过 `AppScaffold` 在实际 AppBar 下方锚定消息，主导航注册 `AppMessageNavigatorObserver` 清理跨路由提示。整体验证与截图见 [全应用 UI 重构](UI_REDESIGN_ZH.md)。

## 原语阶段验证（dev.20 历史记录）与体验指南

静态分析无问题；20 项样板、数值输入、消息反馈、导航和主界面测试通过。覆盖对话框、表单错误、模型选择、发送、工具展开、深色切换、大字号、键盘、进度中退出，以及侧边栏和原会话/草稿的保留。覆盖配色与明暗独立切换、菜单选中状态、大字号菜单、弹窗继承配色、草稿与模型选择保留和退出后恢复默认；另覆盖精确输入与拖动同步、非法值保留、失焦归一化、1.6 倍字号与键盘、自定义 AppBar 高度与页签安全边界、提示期间顶部按钮仍可点击、进入动画不遮挡、替换计时、手动关闭及带提示退出。

此前已检查两套配色、精确数值、聊天和弹窗；本轮另通过 1 项离屏渲染脚本检查浅色与茶紫深色的提示定位，并在提示显示期间切换主题色和明暗。中文视觉检查使用临时加载的系统字体，未修改应用字体配置或打包该字体；字形与真机默认字体可能略有差异。渲染产物和辅助脚本保存在忽略目录 `.dart_tool/ui-lab/` 等位置。

体验步骤：

1. 打开侧边栏 → UI 原语，点击右上角调色盘，在「雾紫／茶紫」间切换；用旁边明暗按钮比较四种组合。切换后查看基础、交互、场景及弹窗颜色，确认原输入和选择仍保留。
2. 在交互组件页留空名称并点击“校验输入”，再填写名称检查错误消失；右侧输入 `0.65` 查看滑块同步，再拖动滑块查看数字回填；输入 `2`、`0.123` 或清空后提交，确认错误提示和有效值保留。
3. 点击成功/信息/警告/错误按钮，确认提示位于整个 AppBar 下方，且顶部按钮、页签仍可点击；连续点击确认只替换消息，等待 3 秒观察自动关闭，再尝试手动关闭；切换明暗、大字号和键盘状态。
4. 尝试开关、标签、对话框、底部弹窗与模拟进度。在场景页展开工具过程，选择模型，输入文字并发送，向下滚动查看管理列表；输入框保持在底部。
5. 返回侧边栏，确认原会话和草稿仍在；重新进入确认样板状态重置。

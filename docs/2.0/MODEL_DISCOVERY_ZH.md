# 本地导入与模型发现收敛设计

2026-09-28。范围为 ServLlama 2.0 的模型获取与管理交互，不新增语音架构或修改推理引擎。此文更新此前语音 ZIP 用户入口与模型库下载入口的设计。

## 功能边界

| 入口 | 行为 |
|---|---|
| 模型库 → 导入本地模型 | 仅 llama.cpp GGUF 单文件、MNN 完整目录 |
| 模型库 → 发现模型 | 语言预设、四份语音预设；在线仓库搜索仅语言模型 |
| 模型库 → 语音模型 | 管理已安装与未完成包，暂停、续传、删除、去使用 |
| 下载管理 | 语言模型、语音模型两个标签，分别使用已有状态来源 |

语音 ZIP 的页面按钮与说明移除，`SpeechModelService.importZip/importArchive/cancelImport`、安全校验和 Python 打包工具保留。已有导入资产不迁移、不删除，仍可使用或删除；不具备下载 URL 的导入资产不提供续传，不放入语音下载管理。此轮不实现语音散文件导入、任意 ONNX 识别、GGUF 分片或额外模型架构。

## 本地导入窗口

窗口标题「导入本地模型」，上方切换 llama.cpp/MNN，下方分别显示 GGUF 单文件或 MNN 目录说明，底部「选择并导入」。明确说明选择完成后即导入，复制到应用存储。采用现有选择后导入接口，无额外预览确认步骤，也不为统一形式扩展 MNN 插件。取消系统选择器不创建模型；导入反馈、重名分配、回滚沿用已有实现。GGUF 的 mmproj 继续在模型设置里管理。

发现模型与导入分开；发现入口在模型库两个标签均可访问，独立语言模型页也保留发现按钮。

## 发现与筛选

保留「推荐」与「在线搜索语言模型」两个标签。推荐列表组合已有语言目录与 `assets/speech/catalog.json`，不复制模型元数据、不新增注册表。

- 公共筛选：名称/引擎关键词、用途（全部、语言模型、语音模型、转录、合成）、引擎。
- 用途限制可选引擎；切换用途清除引擎、安装状态、克隆、体积条件，保留搜索文本。重置清除所有条件。
- 选择语音用途后提供安装状态：全部、未安装、下载中、可用、暂停/未完成；声音克隆（不在转录分类显示）、不超过 200 MiB。
- 安装状态根据模型服务中的包身份（配方与固定 revision）、安装锁、传输进度与资产可用状态计算。暂停模型显示继续下载；下载中的按钮禁用重复安装并提供暂停。
- 语言预设指向仓库，其中可能包含多个量化文件，因此不以仓库级标识猜测「已安装」。在线语言搜索继续使用原来源、格式、综合/下载量/喜欢数排序与分页。
- 搜索无结果有空态。语音服务初始化失败与进行中有反馈，页面不负责初始化或恢复任务。

首批沿用已有四个固定配方：sherpa Whisper tiny int8、sherpa AISHELL3 VITS int8、Crisp Whisper base、Crisp Qwen3-TTS Base 0.6B Q8（含 codec/voicepack）。语音卡片展示用途、引擎、全部依赖总体积、克隆能力、状态与来源链接；明确提示实际兼容性和效果需设备验证。没有可靠元数据的语言范围、多说话人数量不添加猜测性筛选。

## 下载和使用闭环

1. 按既有 Wi-Fi-only 设置确认后，以完整包启动下载；已暂停的包复用同一安装记录，服务安装锁阻止重复安装。
2. 下载和校验仍交给 `SpeechModelService` / `ModelDownloadService`，沿用固定文件大小、SHA-256、空间检查、前台服务与日志。
3. 模型库、发现页和下载管理订阅同一个应用级 `SpeechJobService`，其转发模型服务变化。模型库下载角标统计语言与语音活动传输。
4. 可在发现卡片或语音下载管理暂停，在发现卡片或模型库继续；需要移除时先暂停，再删除未完成包，复用资源引用检查。离开页面不取消任务。
5. 校验完成后卡片变为「转录」/「合成」。点击保存对应模型选择，再打开语音页对应标签；不自动提交任务或加载模型。模型库同样提供去使用操作。
6. 安装失败保留不可用记录，支持续传/删除；应用日志继续记录失败阶段。新页面不改变 LLM 与语音的资源独立边界。

下载管理的语音标签为可下载包安装记录视图，包含已完成记录，不新增与资产生命周期不同的下载历史表。语音 ZIP 离线导入仍由资产所有者独立管理。

## 实现位置

- `model_management_page.dart`：语言导入窗口与独立页面发现入口。
- `model_discovery_page.dart`：推荐组合、筛选、在线语言搜索。
- `speech_catalog_card.dart`：下载状态与下载/暂停/去使用操作。
- `speech_model_service.dart`：复用包身份查找，安装实现不变。
- `speech_models_page.dart`：已安装/未完成语音资产管理及下载管理复用视图。
- `model_library_page.dart` / `downloads_page.dart`：应用级入口和两类下载组合。
- `speech_page.dart`：支持指定初始用途，保持聊天转录及预填合成文本行为。

无数据库迁移，无新依赖，mnn_engine 和参考仓库均未修改。

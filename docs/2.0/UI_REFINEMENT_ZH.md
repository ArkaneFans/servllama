# UI 细化：表单、聊天与模型选择

后续 dev.23 调整助手编辑、聊天图标对齐与模型行尾图标，当前交互以[助手与聊天简化设计](ASSISTANT_UI_ZH.md)为准；以下为 dev.22 交付记录。

2026-10-03，`2.0.0-dev.22+36`。继续采用已确认的雾紫主题，不增加配色、状态存储或 UI 依赖。

## 完成内容

- **表单间距**：MCP、用户档案、助手、供应商、语音合成/转录与参考音色表单使用 `FormListView`，字段、说明与操作之间保持 16 dp。已移除这些表单重复的手工留白；工具权限下拉框、转录分段编辑和 MNN 测试参数也补齐间距。服务器原有 18 dp 分组间距保留，共享文本框圆角统一为 14 dp。搜索框和聊天输入不套用表单列表。
- **MCP 窄屏**：协议选择填满可用宽度，长名称单行省略，修复 360 dp 大字体下的横向溢出。凭证仍支持保留、清除与测试；返回不保存草稿。
- **工具调用**：采用原语页的浅色表面、18 dp 圆角、无常驻边框折叠卡片。折叠时仅显示工具名称、状态图标与展开箭头；状态具有文字提示。展开显示参数、MCP 来源、结果与失败说明。待审批自动展开，提问、允许一次、拒绝、取消后的只读状态与版本归属保持不变。
- **回执导出移除**：聊天及工具记录页共用卡片均不再提供导出，删除专用 `exportReceipt` 方法与中英文文案。已有回执仍可查看和选择复制；不删除历史结果，不影响语音与日志导出。
- **聊天标题**：主标题恢复 14 sp，模型副标题恢复 10 sp。
- **聊天输入**：采用原语的轻描边表面与紧凑内边距，移除渐变和多层阴影；发送使用柔和雾紫填色。空白草稿禁用发送，有附件时可发送，生成时切换为停止。保留模型选择、语音、附件及本地服务控制；云端聊天隐藏不可用的本地服务器按钮。草稿、键盘发送和停止仍由原回调处理。
- **模型选择**：参考 Kelivo / RikkaHub 的文字分组和直接选择列表。供应商标题移除品牌图标与多余副标题，本地引擎状态紧随名称；模型保持小图标、单行名称与选中标记，本地运行/未运行/加载状态在名称后显示，状态或不可用原因可通过提示查看。取消模型库按钮，保留供应商管理、搜索清空和关闭。选中高亮、错误留在弹窗内重试、本地加载保护及禁用供应商过滤不变。

## 简单验收

1. 设置 → MCP → 新增：检查名称、地址、协议、Token 和请求头的间距；放大字体并弹出键盘，表单应可滚动且无横向溢出。返回应丢弃未保存修改。
2. 用户档案、助手、供应商、语音合成和参考音色：依次查看输入与下拉框间距，验证保存与取消仍正常。
3. 聊天中触发工具：折叠卡片应保持简洁，展开可读参数/结果，已保存回执不再有导出按钮。需要审批或回答时仍能就地操作，取消后不能继续审批。
4. 输入栏：空文本不能发送；输入文本或添加附件后可发送，生成时可以停止；本地聊天服务按钮保留，云端聊天不显示它。切换会话和返回后草稿保持。
5. 模型弹窗：分组不显示品牌图标，没有模型库按钮；搜索供应商或模型，检查单行名称、名称后的本地状态图标、选中背景及加载中的反馈。已发布本地服务仍不能被另一模型替换。

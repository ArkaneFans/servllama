# 助手管理与聊天 UI 简化

后续 dev.24 对输入栏比例、助手列表和全局按压反馈进行了[进一步简化](COMPOSER_FEEDBACK_ZH.md)。

2026-10-03，`2.0.0-dev.23+37`。沿用 ServLlama 雾紫 UI 原语：低对比表面、圆角输入框、胶囊标签、16 dp 表单间距和 AppBar 下方消息提示。

## 页面与交互

- 助手列表及设置菜单统一为“助手管理”。点击助手进入编辑，AppBar 显示当前名称；新建尚未命名时显示“助手设置”。列表菜单保留复制和删除，去掉“使用此助手”；聊天中的助手切换继续使用侧边栏。
- 编辑页上方居中显示头像，点击后底部弹窗提供选择图片、选择表情、恢复默认。名称在头像下方，系统提示词标签与输入文字顶部对齐。
- 下方是“本地工具 / 技能 / MCP”三个标签。普通字号均分宽度，大字号允许横向滚动，避免截断标签。三个标签共享编辑草稿，保存时连同名称、头像、提示词和可空聊天模型一并提交；返回丢弃未保存的助手修改。
- 本地工具保留当前时间、向用户提问、网络搜索。勾选搜索后才显示 Bing / DuckDuckGo 和结果数量。技能选择静态文本包，MCP 展开服务后逐个选择工具；管理入口进入独立目录页面，返回后刷新目录。
- 独立技能/MCP 页面空列表时在中间显示图标与说明，右下角“+”导入技能或新增 MCP。非空时显示原有条目，支持删除、MCP 编辑和下拉刷新。
- 聊天助手消息操作行的首个图标与正文左边缘对齐；输入栏首个功能图标与输入光标左边缘对齐。功能按钮保留可点击区域，输入栏不再显示模型名称，模型图标及长按提示保留。
- 模型选择弹窗去掉每个模型后的状态图标与对勾，选中项通过背景高亮表达。本地引擎分组名称后的状态图标、加载进度、状态/不可用原因提示、错误重试与搜索仍保留。

## 功能边界与数据

“使用本地用户档案”整条路径已移除：助手不再读写 `useProfile/profileFields`，`ChatRunConfig` 不再接收档案或把档案加入系统提示词与新 Run 快照。历史配置中这两个键直接忽略，保存助手时自然去除，不增加迁移、双写或兼容模块。用户头像、昵称、称呼与偏好仍保存在本地；已有聊天正文和历史 Run 记录不会被重写。

最大输出 token、温度以及旧“权限与预算”页面的预算编辑控件不再显示。内部推理参数与执行上限仍保留，保存助手时保留已有值；新助手沿用现有默认值（温度 0.7、最大输出 2048 token、8 回合、16 次工具、180 秒）。此调整不意味着取消模型输出或 Agent 执行限制。

权限草稿由助手页内的 `AssistantToolsEditor` 管理，滚动离屏不会丢失。保存前重新读取目录并剔除已删除的技能/MCP 工具，防止旧草稿恢复无效授权；随后读取当前助手配置并通过原 `AssistantProvider` 单次保存。管理页里的导入、删除、MCP 保存属于独立全局操作；取消助手编辑不会撤销这些已经完成的目录操作。

会话绑定助手、同助手会话共用当前模型（dev.30 起）、运行时重新授权、工具调用与消息版本归属、删除助手时级联删除会话等规则保持原实现。没有新增数据库表、依赖或引擎接口；本轮不修改插件和上游仓库。

## 简单验收

1. 设置 → 助手管理，打开现有助手：标题应为其名称，没有“使用此助手”、档案开关、温度和 token 控件；空系统提示词标签位于顶部。
2. 点击头像，依次选择表情/图片、恢复默认；返回不保存应保留原头像，保存后列表、侧栏与消息署名应更新。复制、删除的原规则不变。
3. 在本地工具、技能、MCP 三个标签分别勾选，来回切换并滚到页首：选择仍保留。返回不保存不生效；保存后重新进入能看到全部选择。
4. 在助手页打开技能/MCP 管理，添加或删除目录条目后返回：列表刷新，旧授权不复活。空目录出现居中说明和右下角“+”，MCP 的“+”进入配置页，技能的“+”打开导入选择器。
5. 查看助手消息末尾操作行和聊天输入栏：图标左对齐，没有输入栏模型名称。点模型图标打开弹窗，选中模型只有背景高亮；本地加载仍有进度与失败提示。
6. 切换深色、放大系统字体、打开键盘，确认页面可滚动、标签可完整访问、底部操作不被遮挡。当前已有会话、草稿与本地模型服务应保留。

开发分支：`feature/2.0-assistant-ui`，完成后本地合入 `feature/2.0`，只提交，不 push。用户原有 Gradle 本地 ZIP 配置不提交。

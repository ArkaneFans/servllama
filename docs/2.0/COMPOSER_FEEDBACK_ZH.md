## 完成内容

- 聊天输入栏移除语音图标。“+”移至右侧，紧邻发送按钮；左侧保留模型选择和本地服务控制。语音仍可从侧边栏进入，转录结果页仍支持插入聊天。
- 参考 RikkaHub `ChatInput.kt` 的 30 dp 圆底、18 dp 箭头比例，发送/停止按钮采用 32 dp 圆底、18 dp 图标，并保留 Material 的 48×48 dp 触控区域。其他工具图标维持 20 dp，与 15 sp 输入文字协调。
- 左侧内边距由 14 dp 增至 20 dp，文字起点与左侧工具图标保持对齐；右侧内边距 10 dp，加上发送按钮触控留白，圆底不会紧贴边框。空草稿禁用发送、附件发送、生成时停止和键盘发送行为沿用原逻辑。
- 助手管理条目只显示头像、单行名称和原有操作菜单。移除选中背景、头像勾标与系统提示词摘要。编辑、复制、删除保持原行为；真正的助手选择仍在侧边栏，不改变聊天归属。

## 统一按压反馈

用户报告侧边栏底部按钮、模型库下载按钮在返回时短暂保留按压效果，随后消失。Flutter 默认 InkSparkle 的动画持续 617 ms，页面转场还可能截取控件的中间状态；这个机制与所述闪现一致，但本轮没有连接设备做原现象复现。

参考 Kelivo 的轻量按压反馈，从共享 `AppVisualTheme` 统一采用 `NoSplash.splashFactory`，去掉跨转场的扩散水波；保留短暂按压底色、悬停和键盘焦点反馈。普通 InkWell 的底色统一为 6% 前景色，Material 按钮沿用其状态层。页面、侧边栏、AppBar、弹窗和原语预览继承同一规则。

没有为每个按钮增加延迟导航、重新创建页面或清理业务状态，也没有改动路由转场、键盘焦点与滚动位置。

简单验收：

1. 打开聊天，检查左侧留白、右侧“+”与小圆发送按钮；空文本不可发送，输入内容/附图后可发送，生成期间显示停止。
2. 助手管理只显示头像和名称；当前助手也没有高亮或对勾。点击条目进入编辑，返回后当前聊天不变。
3. 分别点击侧边栏的助手、服务器、模型库、语音、设置，再返回；按钮应恢复静止状态，不重新播放水波。侧边栏保持展开。
4. 模型库 → 右上角下载任务 → 返回，检查图标无残留水波；再验证按住后滑出取消仍有正常反馈，深色与大字体布局无溢出。

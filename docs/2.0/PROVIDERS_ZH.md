## 功能边界

- 预设 OpenAI、Anthropic、Google Gemini、DeepSeek、OpenRouter、SiliconFlow、Alibaba Cloud（百炼）、Zhipu AI（智谱）。预设使用固定 ID，不可删除；地址、密钥、能力、模型列表可编辑，可启用/禁用。新预设默认禁用、模型列表为空，不内置密钥或自动请求网络。
- 自定义供应商继续支持 OpenAI 兼容、Anthropic、Gemini 三种协议，可增删。旧连接保持 ID、地址、密钥和模型列表，默认启用。
- 供应商保存的模型列表是聊天选择的依据。手动添加模型 ID，或从 `/models` 获取候选后勾选添加；获取不自动加入全部模型、不覆盖已有列表。去重、搜索和取消均在编辑草稿中完成，保存后统一生效。
- 禁用保留供应商配置、模型清单、密钥和历史消息，但清空关联助手的当前模型选择；移除模型也不删除聊天。相关会话显示未选择模型，需要用户明确重新选择。禁用/移除当前运行模型会撤销本次请求授权，复用既有 HTTP 取消与 Agent 收尾。
- 本地 llama.cpp 与 MNN 是两个特殊供应商：模型来自现有本地模型库，状态来自 EngineRuntimeProvider，没有第二份模型清单或伪造的云连接。加载/停止由现有运行时管理；下载、导入、删除仍在模型管理中完成。

## 交互

供应商页仅列出远端预设和自定义供应商，不展示本地引擎；本地模型由模型库管理。远端项展示启用状态、模型数量和设置入口；预设无删除按钮，仓库层同时拒绝删除。编辑页保存配置与模型清单，返回放弃未保存的草稿。获取模型失败不清空已有模型；密钥清除草稿不会被旧密钥悄悄替代。

聊天输入栏的模型按钮打开可滚动的底部弹窗：顶部搜索供应商名称/模型 ID，本地模型也匹配显示名；下方按供应商分组。禁用供应商及其模型完全隐藏，搜索也不显示；空列表提供管理入口。选择远端模型更新当前会话；选择本地模型后执行加载和私用 HTTP 服务启动，成功才关闭弹窗，失败保留错误提示和重试入口。

加载失败原因直接显示在弹窗的滚动内容顶部并保留模型行，重新点选即可重试。加载期间禁止重复点选和更改会话；关闭弹窗不等于取消已经明确发起的本地启动，运行状态仍由服务中心管理。

本地选择遵循单 LLM 驻留规则：复用已运行的同一模型；切换私用模型先停止旧实例；其他模型正在对外提供服务时，不从聊天静默停服或改写其目标，提示先在服务中心停止。云端模型选择不停止本地服务。语音驻留与此独立。

助手的“聊天模型”复用同一弹窗，保存后用于该助手所有会话；编辑页不加载本地模型。聊天中选模也更新所属助手。详见[会话与模型选择](CONVERSATION_ASSISTANTS_ZH.md)。

## 数据与实现

沿用 `AiConnection` / `ai_connections` 和 `models: List<String>`，增加 `enabled` 字段；产品名称改变不改持久 ID、表名或历史 Run 格式。预设目录只提供首次缺失配置，之后不覆盖用户修改。无需新数据库表、状态管理器或供应商 SDK。

初始化在一个事务中补齐缺失预设，保留已有配置。dev.15 移除早期 2.0 的 `providerCatalogV1` 模型补全迁移；助手或会话的历史模型引用不再自动加入供应商列表。缺失模型需用户显式添加，不自动更换服务商。

保存沿用 Secure Storage 密钥引用，数据库失败回收新密钥，成功后再移除被替换的旧密钥。配置写入以 revision 检查过期编辑；模型发现使用当前草稿地址、协议和密钥，关闭编辑页取消未完成的网络请求。日志沿用既有连接/模型事件，仅记录 ID、协议、数量、时长和错误类别。

模型发现沿用协议客户端：OpenAI 兼容读取 `/models`；Anthropic 按 `has_more/last_id` 翻页，Gemini 按 `nextPageToken` 翻页并移除模型名的 `models/` 前缀。每次接收超时 30 秒、最多 32 页与 5000 个去重模型，缺失或重复分页游标按失败处理，不将部分结果显示成完整清单。候选不证明模型支持聊天、图片或工具，能力须按模型说明单独设置并用真实请求确认。

请求启动与 Agent 副作用前共用 `ChatRunConfig.authorizedBy`：供应商须启用且模型仍在清单中；改名、增加模型不打断现有请求，禁用、移除当前模型或改变凭据域会撤销授权。仅隐藏 UI 选项不能替代运行时检查。

## 验收

1. 首次进入有八个远端预设且不可删除；启用/禁用、密钥及模型清单重启保留，自定义供应商可删除。
2. 手动添加去除首尾空白、拒绝空 ID、去重；获取模型可搜索、勾选、取消，仅添加所选项；失败和取消不影响原清单。
3. 底部弹窗搜索供应商/模型，保留本地、已启用远端和空清单，过滤禁用供应商；选中远端后发送使用对应供应商和模型。
4. 点选本地模型触发加载启动，复用已加载模型，错误可重试；发布中的不同模型不可被聊天切换。选择云模型不停止本地服务。
5. 移除被引用模型或禁用供应商，旧消息保留，当前目标不可发送，恢复配置后可继续；进行中的工具请求按撤权路径收尾。
6. 助手当前模型影响其所有会话；删除的模型不会在重启时自动补回，缺失目标需用户重新选择。
7. 360 dp、大字体和键盘打开时，供应商编辑、候选模型列表和底部弹窗可滚动、无溢出。

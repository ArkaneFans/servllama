# ServLlama 2.0 全应用 UI 重构

## 设计与边界

正式应用使用已确认的雾紫配色；茶紫仍只供 UI 原语比较。共享同一套明暗色、文字层级、18 dp 卡片、14 dp 输入框、24 dp 弹窗与 48 dp 操作目标。页面通过中性表面和留白分组，减少重复边框、过重字重和装饰色。助手消息仍使用助手头像与名称，时间、模型和工具回执保留原有归属规则。

本次调整呈现和交互，不迁移数据库、不改变推理资源、HTTP、下载或 Agent 权限。继续保留侧栏展开状态与会话草稿，后台任务不依赖页面生命周期。

## 三步实施

1. **共享基础**：将原语主题与数值控件移到 shared；全应用使用雾紫主题。公共设置卡片、按钮、输入框、筛选标签、页签和弹窗采用统一参数。短暂通知在实际 AppBar 下方显示，错误详情与字段校验仍在原位保留。
2. **页面与图标**：梳理聊天、侧栏、设置、供应商、模型库/发现/下载、助手、技能/MCP、语音、服务器与日志。下载设置收进设置首页的通用分组，进入独立页后管理下载来源、凭证、并发、网络和暂存清理。列表保留搜索、状态与关键操作，详情按需展开。内置 SVG 图标，统一模型/供应商识别，保留引擎及就绪状态文字。
3. **回归与交付**：校验路由、返回、草稿、模型筛选、精确输入、错误消息与通知生命周期；检查明暗主题、窄屏、大字号及键盘。构建 APK 并核对版本、签名和原生库。未执行的真机/推理验证明确记录。

## 图标规则

供应商先按稳定预设 ID，再按完整域名或子域名、已知名称匹配；不把 OpenAI 兼容协议视为 OpenAI 品牌。模型从实际模型名称/路径末段优先识别家族，蒸馏模型保留发行家族（如 DeepSeek-R1-Distill-Qwen 显示 DeepSeek）。未知名称使用供应商或通用图标。图标只用于辨识，不能作为模型能力、可信度或就绪状态依据。

图标来自 `@lobehub/icons-static-svg` 1.95.1，MIT。dev.33 起内置 21 个 SVG，其中 17 个采用官方彩色版本，保留品牌填充与渐变。`AiIdentityIcon` 不再使用整图 `ColorFilter`，只通过 `SvgTheme.currentColor` 适配素材中的单色前景；OpenAI、Anthropic、Grok、Moonshot 保持单色。Kimi 彩色素材原本固定白色的 K 字形改为 `currentColor` 以适配浅色背景，蓝色标记不变，此项修改单独记录来源与哈希。

Claude、Gemma、Kimi 模型分别使用自身标志，与 Anthropic、Gemini、Moonshot 区分。供应商预设标识和模型选择数据不变。所有使用共享组件的供应商管理、模型能力配置、聊天模型弹窗/输入栏、模型库/发现/下载以及服务器模型信息同步生效；未知模型维持原来的供应商或通用图标回退。

不联网加载、不新增依赖。来源和逐文件 SHA-256 见 `assets/ai-icons/sources.json`；许可证随包保留并加入开源许可页。文件沿用本地品牌名，来源清单记录实际采用的上游 `*-color.svg` 文件名。

## 验收路径

1. 安装 dev.21，依次打开聊天、侧栏、设置、服务器、模型库、语音与日志；切换浅色/深色，检查雾紫选中状态、中性背景、文字对比度和返回操作。侧栏打开页面后返回，应继续保持展开，原会话与草稿不变。
2. 设置 → 通用 → 下载：调整下载线路、Wi-Fi 限制及并发数，返回后重新进入应保留设置。下载凭证仍按原存储规则处理。首页不再展示整组下载详细选项。
3. 设置 → 供应商：搜索供应商名称或已保存模型，清空搜索恢复列表。检查预设不可删除、启用开关和自定义供应商删除；点击行进入原有详细配置。
4. 聊天底部模型选择：检查常见模型家族图标、本地模型状态、供应商分组与禁用过滤。图标优先使用模型家族，未知模型回退供应商/通用图标。选择本地模型仍沿用加载规则，云端选择不会触发本地推理。
5. 聊天显示助手/用户头像与名称，模型按钮显示名称；助手回复保留更宽阅读空间，时间与模型位于末尾。检查消息版本、工具过程折叠、重新生成和取消等原有操作。
6. 助手温度、语音合成速度与播放速度可拖动或精确输入；非法小数不覆盖有效值。服务器整数滑块保留拖动结束后一次提交与原范围夹取行为，并扩大右侧输入区域。
7. 复制消息/地址或触发可恢复错误：提示应在当前 AppBar（含页签）下方 12 dp，约 3 秒消失；连续提示替换前一条，关闭与返回页面不残留；弹窗内报错仍可见。详细错误与业务状态仍在原页面呈现。
8. 模型库语言/语音页签、发现筛选、下载任务、技能/MCP 和语音任务继续按原功能验证。本次不要求为验证样式下载大模型。

## 实现取舍

共享层集中主题、页签、消息和图标规则；原语页直接复用，避免维护两套实现。沿用现有路由、Provider 与业务服务，没有增加设计系统依赖或平行页面状态。引擎/任务语义色仍保留独立标签；预设图标通过稳定 ID、域名边界和模型名识别，不从请求协议猜测品牌。

应用继续遵守系统主题模式，主色固定雾紫。设置、列表与表单采用相同表面、字号和圆角；服务器高级设置、模型导入和迁移流程的业务顺序保持原契约。
